# TAREFAS Android — Alpha 2.4.8.6

Base funcional: Alpha 2.4.8.5 / base 2.4.8 / build 290
Nova versão APK: 2.4.8.6 / build 292
Canal: Alpha
Formato: APK

## Correção principal
- Corrige na camada Android nativa a duplicidade de solicitações de biometria.
- Apenas um BiometricPrompt pode ficar ativo por vez.
- Chamadas concorrentes ao método nativo authenticate() entram na mesma autenticação em andamento.
- O resultado de uma autenticação concluída é entregue às chamadas pendentes.
- Erros ou cancelamento também são propagados às chamadas pendentes e liberam a trava para a próxima tentativa.
- Mantida a regra de biometria somente em novo início real do aplicativo.

## Integridade da correção
- O plugin nativo contém trava compartilhada authenticateInProgress.
- Chamadas aguardando são mantidas em pendingAuthenticateCalls.
- O plugin possui caminhos separados para resolver/rejeitar todas as chamadas pendentes.
- O código fonte cria apenas um BiometricPrompt para o fluxo de autenticação.

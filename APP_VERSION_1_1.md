# TAREFAS Android V1.1

Base web: TAREFAS V7.5.2
App version: 1.1.0

## Atualizações
- Sessão persistente exclusiva do APK: após o primeiro login, o usuário permanece autenticado até sair manualmente.
- Notificações locais nativas Android com Capacitor.
- Camada mobile exclusiva do APK, sem alterar os HTMLs do site em produção.
- Responsividade global para todas as abas, incluindo formulários, modais, tabelas e containers.
- Melhorias de viewport e toque em telas pequenas.
- Build Android automático via GitHub Actions.
